# 赵诣框架评分卡

> 用赵诣的投资方法给任意基金打分，衡量“与赵诣投资风格的契合度”。

## 六维评分

| 维度 | 权重 | 评分依据 |
| --- | --- | --- |
| 1. 长坡厚雪与增量空间 | 20分 | 所投行业是否市场空间大、成长周期长、竞争格局良好？增长是否来自技术进步、国产替代、应用扩张、出海或供需改善等真实增量？ |
| 2. 基本面与公司质量 | 20分 | 重仓公司是否具备清晰护城河、稳定治理、优质客户和高质量盈利？市场份额与竞争优势是否持续增强？ |
| 3. 制造业硬实力与全球竞争力 | 15分 | 公司能否低成本、高一致性地规模化交付？是否具备技术、供应链、专利、资金及海外经营能力？非制造业公司可对应考察其商业模式复制能力。 |
| 4. 成长兑现与估值性价比 | 15分 | 收益预期是否建立在可跟踪的盈利增长上？是否用渗透率、市场份额、利润率估算稳态盈利？买入估值是否合理，是否避免为短期情绪和主题支付过高价格？ |
| 5. 组合结构与风险控制 | 15分 | 是否做到行业分散、个股集中？是否避免单一赛道或单一风险因子失衡？组合内企业的现金流、资本开支和生命周期是否具有互补性？ |
| 6. 长期视角与方法一致性 | 15分 | 持仓是否相对稳定、换手是否与长期研究相匹配？基金经理是否持续跟踪企业经营并动态迭代能力圈？长期收益能否由企业盈利兑现而非单纯估值扩张解释？ |

## 评级标准

| 总分 | 评级 | 含义 |
| --- | --- | --- |
| 80-100 | 高度契合 | 非常像赵诣会采用的投资组合 |
| 60-79 | 较为契合 | 具有较明显的赵诣方法特征 |
| 40-59 | 一般 | 部分维度契合，但底层逻辑或组合结构存在差异 |
| 20-39 | 不太契合 | 风格偏离较大，仅有少量共同特征 |
| 0-19 | 不契合 | 投资逻辑和组合行为几乎相反 |

## 打分流程

1. 准备待评基金最近至少四期定期报告、最新持仓、行业分布、换手率、规模和基金经理任职期业绩。
2. 区分基金合同限制与基金经理主动选择，避免把主题基金的行业集中简单归因于个人风格。
3. 按上表六维逐项给分，每一维均列出支持证据、反向证据和待核实项。
4. 汇总总分与评级，并与赵诣在管基金的行业结构、集中度、换手和选股逻辑进行对照。
5. 如关键数据缺失，不以推测补齐，相关评分标注“暂定”或“需核实”。

## 评分口径提示

- 第1维重点看行业是否具备长期真实需求和良好竞争格局，不因持有新能源、AI、军工等赵诣关注的行业而自动给高分。
- 第2—4维是核心，若公司质量、规模化能力或估值纪律明显不符，即使行业重合，总体也不应评为“高度契合”。
- 第5维中的“个股集中”不是越高越好；只有在行业风险分散、研究深度充分且流动性可承受时才加分。
- 第6维应结合完整任期判断，短期业绩、单季度换手或某一时点持仓不能单独代表长期风格。

## 重要提醒

- 这套评分衡量的是“**与赵诣投资风格的契合度**”，不是基金质量或未来收益的绝对评判。
- 对被动指数基金、单一行业主题基金和任职期过短的基金，评分解释力有限，应单独标注产品约束。
- 个股基本面、估值、海外竞争力等无可靠数据时标注“需核实”。
- 评分结果仅用于研究，不构成投资建议。
